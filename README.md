## 🌟 פרויקטים נבחרים

### 🏮 מערכת לניהול אירועי מכירה והגרלות (Auction Management System)
* **צד שרת:** פיתוח REST APIs ב-ASP.NET Core (C#), שימוש ב-SQL Server ובניהול זיכרון מטמון עם Redis.
* **צד לקוח:** ממשק משתמש דינמי ומתקדם ב-Angular.
* **כלים:** סביבת פיתוח מבוססת קונטיינרים באמצעות Docker.

### 🛒 פלטפורמת מסחר אלקטרוני (E-Commerce Platform)
* אפליקציית אינטרנט מלאה ורספונסיבית שנבנתה מאפס.
* **Stack טכנולוגי:** Node.js, React, ו-MongoDB.
* **מאפיינים:** שימוש ברכיבי UI מתקדמים, מנגנוני אבטחה ואופטימיזציה של בסיס הנתונים.

### 🤖 פרויקטים בשילוב Generative AI
* פיתוח ואינטגרציה של רכיבי בינה מלאכותית לתוך ארכיטקטורת תוכנה מסורתית.
* **מיקוד:** עבודה מעשית עם OpenAI API, כתיבת פרומפטים (Prompt Engineering), ושימוש ב-Model Context Protocol (MCP) וב-Agents.
